## 🎬 شاشة الترحيب

**المسار**: `/Onboarding`

### الغرض
تقديم التطبيق للمستخدمين الجدد وشرح الميزات الأساسية والهدف من التطبيق.

### المميزات الرئيسية
- ✅ شاشات ترحيب متعددة (2+ شاشة)
- ✅ رسوم توضيحية وأيقونات
- ✅ عناوين فرعية شارحة
- ✅ تبديل اللغة (عربي/إنجليزي) في الأعلى
- ✅ مؤشرات التقدم (Dots indicator)
- ✅ زر "ابدأ الآن" للدخول إلى التطبيق

### التفاعلات

```
المستخدم ينقر "ابدأ الآن"
    ↓
يتم حفظ حالة (has_seen_onboarding = true)
    ↓
إعادة توجيه إلى الشاشة الرئيسية (Home)
```

### الملاحظات التقنية
- ✅ تغيير اللغة يؤثر على جميع النصوص فوراً
- ✅ يتم حفظ حالة الترحيب في قاعدة البيانات (UserSettings)
- ✅ عدم ظهور الترحيب مرة أخرى إذا تم رؤيته من قبل

### حالات الاستخدام

```
حالة أولى:
├─ المستخدم يدخل التطبيق
├─ له رؤي الترحيب (has_seen_onboarding = false)
└─ يتم عرض Onboarding

حالة متكررة:
├─ المستخدم يدخل التطبيق
├─ رأى الترحيب من قبل (has_seen_onboarding = true)
└─ يتم الانتقال مباشرة إلى Home
```

## 🏠 الشاشة الرئيسية

**المسار**: `/` أو `/Home`

### الغرض
عرض قائمة بجميع قوائم الحظر النشطة والمجدولة وإتاحة إنشاء قوائم جديدة.

### المميزات الرئيسية
- ✅ عرض بطاقات (Cards) لكل قائمة حظر
- ✅ عرض معلومات القائمة: اسم، حالة، نوع حظر، مدة
- ✅ زر "إنشاء قائمة" عائم في الأسفل
- ✅ رسالة حالة فارغة عند عدم وجود قوائم
- ✅ خيارات تحرير وحذف (حسب نوع الحماية)

### محتوى البطاقة

```
┌─────────────────────────┐
│ اسم القائمة            │
│ حالة: نشط/غير نشط    │
│ النوع: فوري/مجدول     │
│ المدة: X يوم            │
│ الفئات: X محددة        │
│ [تعديل] [حذف]         │
└─────────────────────────┘
```

### التفاعلات

```
عرض القوائم ← البيانات من قاعدة البيانات
    ↓
[إنشاء قائمة] → الانتقال إلى CreateList (خطوة 1)
    ↓
[تعديل] → الانتقال إلى CreateList مع بيانات القائمة
    ↓
[حذف] → عرض تأكيد → حذف من قاعدة البيانات
```

### ملاحظات مهمة
- ✅ **بدون حماية**: يمكن التعديل والحذف مباشرة
- ✅ **وضع الحماية الصارم**: يظهر رسالة تحذيرية بدلاً من أزرار التعديل
- ✅ يتم تحميل البيانات من قاعدة البيانات عند الدخول
- ✅ تحديث فوري عند إنشاء/حذف/تعديل قائمة (TanStack Query invalidation)

## 📝 إنشاء/تعديل قائمة الحظر

**المسار**: `/CreateList` (مع أو بدون `?id=XXX` للتعديل)

### المقدمة
هذه العملية عبارة عن تدفق متعدد الخطوات (Stepper) يدعم الاختيار الحر والتخطي الذكي.

### ملاحظات تقنية عامة
- ✅ **التحقق من الصلاحيات**: التحقق من حدود القوائم (3 قوائم للمجاني، غير محدود للـ Premium)
- ✅ **التحقق من وضع الحماية الصارم**: التحقق من حد أقصى واحد للمجاني
- ✅ **حفظ الحالة**: حفظ تلقائي في قاعدة البيانات
- ✅ **التعديل**: تحميل البيانات الموجودة من URL parameters (`?id=XXX`)

### الخطوة 1️⃣: اسم القائمة

**الوصف**: تحديد اسم فريد لقائمة الحظر

**المدخلات**:
- حقل نص: اسم القائمة (مثال: "وقت التركيز")

**الحد الأدنى**: يجب ملء الحقل قبل المتابعة

**مثال**:

```
┌─────────────────────────────┐
│      ⚙️ (أيقونة إعدادات)   │
│                             │
│  اختر اسماً يصف الهدف       │
│  ┌─────────────────────────┐│
│  │ مثال: وقت التركيز      ││
│  └─────────────────────────┘│
└─────────────────────────────┘
```

**الوصف**: إضافة المواقع والتطبيقات والفئات المراد حظرها

**المدخلات**:

#### أ) المواقع

┌──────────────────────┐ ┌──────┐

العناصر المضافة:

```

#### ب) التطبيقات

العناصر المضافة:

```

#### ج) الفئات

```
🏷️ الفئات (شبكة اختيار)
┌──────────┬──────────┐

│ التواصل  │ والريلز  │
├──────────┼──────────┤
│ الألعاب  │ التسوق   │
└──────────┴──────────┘
```

**الفئات المتاحة**:
- 🔴 وسائل التواصل الاجتماعي
- 🎬 الشورتس والريلز
- 🎮 الألعاب
- 🛍️ تطبيقات التسوق
- 🛵 تطبيقات التوصيل
- 💕 تطبيقات المواعدة
- ⚠️ محتوى للبالغين

### الخطوة 3️⃣: الإعدادات المتقدمة (اختياري)

**الوصف**: تخصيص تجربة الحظر بميزات إضافية

**الخيارات المتاحة**:

```
┌─────────────────────────────────┐
│ ☑️ وضع NoNet (Block all)       │ ← منع كل الإنترنت
│ ☐ وضع الطائرة                  │ ← تفعيل وضع الطائرة
│ ☐ حظر الإشعارات                │ ← منع الإشعارات
│ ☐ تدرج الرمادي               │ ← شاشة رمادية
│ ☐ مرشح الضوء الأزرق           │ ← حماية العينين
│ ☐ حظر متجر التطبيقات          │ ← منع تحميل التطبيقات
│ ☐ حظر VPN                      │ ← منع تجاوز الحظر
│ ☐ حظر الإعدادات               │ ← منع تغيير الإعدادات
└─────────────────────────────────┘
```

**ملاحظة**: جميع هذه الخيارات اختيارية، والمستخدم يمكنه تخطي الخطوة

### الخطوة 4️⃣: نوع الحظر (مدة الحظر)

**الوصف**: تحديد كيفية تفعيل الحظر

#### الخيار الأول: ⏱️ حظر فوري (Instant)

```
يبدأ الحظر الآن لمدة محددة
┌────────────┐ ┌────────────┐ ┌────────────┐
│ الأيام    │ │ الساعات    │ │ الدقائق    │
│ 0 إلى 360 │ │ 0 إلى 23   │ │ 0 إلى 55   │
└────────────┘ └────────────┘ └────────────┘

مثال: 5 أيام + 3 ساعات + 30 دقيقة
```

#### الخيار الثاني: 📅 مجدول (Scheduled)

```
حظر في أيام وأوقات محددة
┌─────────────────────────────┐
│ الأحد: 9:00 - 17:00       │
│ الاثنين: 9:00 - 17:00     │
│ الثلاثاء: 9:00 - 17:00    │
└─────────────────────────────┘
[+ إضافة فترة أخرى]
```

#### الخيار الثالث: ⏲️ حد زمني (Time Limit)

```
سماح بوقت محدود يومياً
┌────────────┐ ┌────────────┐
│ الساعات    │ │ الدقائق    │
│ 0 إلى 12   │ │ 0,15,30,45 │
└────────────┘ └────────────┘

مثال: ساعة واحدة يومياً فقط
```

#### الخيار الرابع: ♾️ للأبد (Forever)

```
حظر دائم بدون نهاية

💡 التوصيات:
  • حظر المحتوى الإباحي
  • حظر تطبيقات القمار
  • حظر المواقع المدمنة بشدة

⚠️ التحذير:
  لن تتمكن من إيقاف الحظر بعد التفعيل
```

### الخطوة 6️⃣: مستوى الحماية

**الوصف**: تحديد صرامة الحظر ومستوى التحكم

#### الخيار الأول: 🔓 بدون حماية (No Protection)

```
┌────────────────────────────┐
│ 🛡️ بدون حماية             │
│                            │
│ يمكنك تعديل أو حذف      │
│ القائمة في أي وقت        │
│                            │
│ مناسب عندما:              │
│ • تجربة التطبيق لأول مرة  │
│ • حظر مؤقت (عمل/دراسة)   │
│ • تحتاج مرونة في التعديل │
└────────────────────────────┘
```

#### الخيار الثاني: 🛑 وضع الحماية الصارم (Hard Mode)

```
┌────────────────────────────┐
│ 🔴 وضع الحماية الصارم    │
│                            │
│ لا يمكن التعديل أو       │
│ الحذف إلا بالتواصل مع   │
│ الدعم                      │
│                            │
│ مناسب عندما:              │
│ • حظر محتوى إباحي       │
│ • التخلص من عادة سيئة   │
│ • فشلت المحاولات السابقة│
└────────────────────────────┘

⚠️ تحذير:
   لن تتمكن من تعديل هذه القائمة
   إلا بالتواصل مع الدعم عبر البريد
```

**ملاحظة تقنية**: اختيار Hard Mode يؤدي إلى:
- ✅ ظهور الخطوات 7 و8 (الشريك والعقاب) فوراً
- ✅ تحديث شريط التقدم (Progress Bar) ديناميكياً (7 خطوات بدلاً من 9)
- ✅ تخطي الخطوات 7 و8 عند العودة للخلف في حالة عدم اختيار Hard Mode
- ✅ عدم ظهور أزرار التعديل/الحذف في الشاشة الرئيسية
