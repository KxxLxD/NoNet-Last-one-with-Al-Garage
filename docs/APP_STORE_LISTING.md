## 📝 Notes for App Review

```
This is a digital wellness app that uses Apple's FamilyControls and ManagedSettings
APIs to block distracting apps and websites — same APIs as Apple's built-in Screen Time.

Key points for the reviewer:

1. AUTHENTICATION
   The app works locally without any backend. Two options:
   - "Sign in with Apple" (preferred)
   - Email + password (LOCAL ONLY — there is no server. A clear banner explains this.)

2. FAMILY CONTROLS
   Required for the core blocking feature. The usage description in Info.plist
   explains the local-only nature.

3. TESTING THE BLOCKING FEATURE
   IMPORTANT: Family Controls does NOT work in iOS Simulator. The reviewer must use
   a physical device:
   a. Launch the app
   b. Complete onboarding (or skip via "later")
   c. Tap "+" to create a list
   d. Add a name, pick "Block Now" + a duration
   e. Open the items editor → tap "Apps" → grant Screen Time when prompted
   f. Pick a few apps via FamilyActivityPicker
   g. Tap Save → Done
   h. The picked apps are now shielded by iOS

4. IN-APP PURCHASES
   Monthly (com.nonetapp.monthly) and Yearly (com.nonetapp.yearly) subscriptions.
   Both include a 7-day free trial. Restore Purchases button is present.
   Privacy: payments are handled entirely by StoreKit / Apple.

5. PRIVACY
   - No personal data collected
   - No analytics or tracking SDKs
   - No third-party network calls
   - All user data (lists, settings) stored locally
   - Privacy Manifest (PrivacyInfo.xcprivacy) declares no tracking

If anything is unclear, contact support@nonet.app — we respond within 24 hours.
```
