## 🎓 الدروس المستفادة (هذه الجولة)

### ✅ ما نجح
1. **منهجية gstack محكمة** — كل phase له output واضح يبني على السابق
2. **تقسيم Commits منطقياً** — feature commit + docs commit يسهّل مراجعة PR
3. **Privacy Manifest بسيط** — XML قصير لكنه ضروري لـ App Store Review
4. **Tests الـ pure** أسهل بكثير من tests UI/integration — تركيز على Core/ كان الصواب

### ⚠️ ما يحتاج الانتباه
1. **Tests Target و BlockingMonitor Target يحتاجان Xcode UI** — لا يمكن إضافتهما برمجياً بأمان. وثّقت بوضوح.
2. **استضافة HTML خارج repo** — يجب على المستخدم رفعها لـ GitHub Pages أو Vercel وربط URL.
3. **Family Controls Distribution Entitlement** — أيام إلى أسابيع انتظار من Apple. يجب طلبه **الآن** قبل أن تكتمل باقي التحضيرات.
4. **App Store Connect setup** — يحتاج وقت لإنشاء المنتجات والـ subscription group.
