## 2. نطاق الإصدار الأول (v1)

### ✅ يبقى
- القوائم (إنشاء، تعديل، حذف)
- الجدولة
- الاستراحات (Breaks) — زي ما هي
- الوضع الصارم (Hard Mode) — منفصل عن الشريك زي الحين. وهو شغّال: ما تقدر تعدّل أو توقف أو تحذف القائمة، ولا تحذف التطبيق
- مستويات الحماية لكل قائمة: بدون · صارم · بالشريك
- شريك المساءلة — PIN محلي، ينزل في نسخة المتجر (كان TestFlight فقط)
- خيار حظر مواقع البالغين في كل قائمة
- الأسئلة الشائعة (FAQ)
- صفحة «عن التطبيق»
- قسم اللغة في الإعدادات

### 🗑️ ينشال
- زر «مشاركة التقدم» وسجل جلسات التركيز
- زر «معاينة شاشة الحظر» في الإعدادات
- تاب «الدليل» (المحادثة) ← يتحول لقائمة نصائح ثابتة داخل الإعدادات
- شاشة الترحيب عند الفتح (تنتقل للإعدادات › الحساب)
- أسئلة جمع البيانات في الـOnboarding القديم
- النتيجة: تابين فقط (الرئيسية + الإعدادات)

### ⏳ «قريباً»
- الاشتراك Premium
- روابط مجتمع واتساب وتيليجرام

### 🔢 الحدود
- المجاني: 3 قوائم
- القائمة الرابعة ← صفحة Premium تشرح الميزات القادمة + زر «نبهني لما ينزل»
- ⚙️ بدون سيرفر: «نبهني» ينحفظ على الجهاز، ونعرض إعلان داخل التطبيق لما ينزل Premium بتحديث

## 5. ميزة «احظر للأبد» 🆕
- **مجانية للأبد**، زر واحد
- تحظر: الإباحية + القمار + المواعدة
- صارمة: ما ينحذف التطبيق من الجوال
- مكانها: في الـOnboarding + زر في الرئيسية
- بعد التفعيل: علامة صغيرة فقط إنها مفعّلة
- **الفك:** يطلب الفك ← ينتظر 360 يوم من لحظة الطلب، ويقدر يلغي الطلب
- **الشريك:** يقدر يفكها قبل الـ360 يوم برمزه (يكتبه بنفسه على الجوال)

### ⚠️ قيد تقني
- **المواقع:** نقدر نحطها جاهزة (قائمة دومينات مسبقة) ✅
- **التطبيقات:** Apple ما تسمح بقائمة تطبيقات جاهزة — معرّفات التطبيقات مشفرة ولكل جهاز
- **القرار:** بنفس الشاشة مفتاح «اقفل كل تطبيقات 17+» مع توضيح إنه يقفل معها تطبيقات عادية 17+ (يغطي معظم المواعدة والقمار)

### بعد طلب الفك
- «باقي 359 يوم» + نص تحفيزي
- زر «إلغاء الطلب» + زر «اطلب من شريكي» (يفتح الواتس)

### التأكيد قبل التفعيل (Hard Mode و«احظر للأبد»)
- شرح بسيط وش بيصير + زر «فهمت، فعّل»

---

## 6. شريك المساءلة
- **رمز واحد** في الإعدادات (مو رمز لكل قائمة) — ⚙️ يحتاج تعديل `PartnerLock` (حالياً لكل قائمة)
- كل قائمة تختار بس «محمية بالشريك»
- **الرمز:** الشريك يكتبه بنفسه على الجوال — ما ينرسل أبداً
- **الواتس:** بس لطلب الفك («اطلب من شريكي»)
- يقدر يفك «احظر للأبد» قبل الـ360 يوم

### شاشة الشريك (في الإعدادات)
- اسم الشريك + رمز من **4 أرقام** — ⚙️ الكود الحالي يسمح 4–6، نثبته على 4
- بدون رقم جوال ← زر «اطلب من شريكي» يفتح الواتس برسالة جاهزة ويختار المستخدم المحادثة
- **تغيير أو حذف الشريك يحتاج رمز الشريك الحالي** — عشان ما يتخطى الحماية بحذف الشريك
- **نسيت الرمز:** زر «نسيت الرمز» ← الشريك ينفك بعد 7 أيام انتظار (ما يشمل «احظر للأبد» — يبقى 360 يوم)

## 7. التصميم

| البند | القرار |
|---|---|
| الطابع | Liquid Glass (نظام Apple الجديد: زجاج شفاف وعمق) |
| الوضع | فاتح فقط في v1 |
| الخط | خط النظام (SF + العربي الافتراضي)، يدعم كبر الخط (Dynamic Type) |
| الحركة والاهتزاز | بدون في v1 (أسرع للإطلاق) |
| أيقونة لكل قائمة | لا — الاسم بس |
| الأزرار | أسلوب Liquid Glass: الأساسي ملوّن (كحلي)، الثانوي زجاجي |
| صيغة الوقت | ساعة محددة في كل مكان: «ينتهي 6:00 ص» |

### لوحة الألوان
اللون الغامق للأزرار والعناوين بس — الخلفيات فاتحة.

| الدور | اللون |
|---|---|
| الأساسي | كحلي غامق `#0F1B3D` |
| الثانوي | كحلي فاتح `#3B4A6B` |
| الخلفية | رمادي فاتح `#F3F4F6` |
| السطح (البطاقات) | أبيض `#FFFFFF` |
| النص | `#111827` |
| النص الثانوي | رمادي بارد `#6B7280` |
| الحدود | `#E5E7EB` |

### ألوان حالات القائمة (إشارات واضحة)
| الحالة | اللون |
|---|---|
| شغالة | أخضر |
| مجدولة | برتقالي |
| متوقفة | رمادي |

> ⚙️ `AppColors.swift` يتنظف ويتبدّل للوحة هذي (يشيل الأزرق والتكرار)

### الرئيسية (من فوق لتحت)
1. **بطاقة القائمة الشغالة:** نص بسيط — الاسم + «ينتهي 6:00 ص». لو ما فيه قائمة شغالة ← زر «ابدأ الحظر»
2. **بطاقة «احظر للأبد»:** بزر «فعّل» ← تتحول لعلامة صغيرة بعد التفعيل
3. **بطاقة الأذونات:** تظهر فقط لو ناقص إذن
4. **القوائم**

```
┌──────────────────────────┐
│ النوم                    │
│ ينتهي 6:00 ص             │
└──────────────────────────┘
```

### الحالة الفاضية (ما فيه قوائم)
- أيقونة درع كبيرة
- «ابدأ أول قائمة حظر»
- زر «أنشئ قائمة»

### بطاقة القائمة (في الرئيسية)
بسيطة: الاسم + الحالة (شغالة / مجدولة / متوقفة) + زر تشغيل — بدون أيقونة
```
النوم                   [▶]
مجدولة · 10م ← 6ص
```

### تفاصيل القائمة (لما يضغط على قائمة)
```
النوم
شغالة · ينتهي 6:00 ص

المحظور     7 تطبيقات · 3 مواقع
الوقت       كل يوم 10م ← 6ص
الحماية     بالشريك
الاستراحات  1 من 2 باقية

[ ابدأ استراحة ]
[ أوقف ]
تعديل · حذف
```

### إيقاف قائمة محمية
- **صارم:** الأزرار معطّلة + «تنفتح 6:00 ص»
- **شريك:** يطلب الرمز + زر «اطلب من شريكي» (واتس)

### بطاقة «احظر للأبد» (قبل التفعيل)
- نبرة روحانية مع آية ﴿قُل لِّلْمُؤْمِنِينَ يَغُضُّوا مِنْ أَبْصَارِهِمْ﴾
- زر «فعّل»

### شاشات الـOnboarding
- نظيفة زي إعداد أجهزة Apple: أيقونة كبيرة + عنوان + جملة + زر
- نقاط الصفحات تحت

### إنشاء قائمة
شاشة وحدة نظيفة: الأساسي ظاهر، والباقي مطوي تحت «خيارات إضافية»
- **ظاهر:** الاسم، وش تحظر (تطبيقات + مواقع)، متى (الحين / جدول)، المدة
- **مطوي:** الحماية، الاستراحات، مواقع البالغين

### الإشعارات
- بداية القائمة المجدولة («بدأ حظر النوم»)
- نهاية القائمة («انتهى حظر النوم 🎉»)
- قبل دقيقة من نهاية الاستراحة
- تذكير يومي بنص تحفيزي

### أيقونة التطبيق
- Liquid Glass بطبقات، تتصمم بـ Icon Composer
- الفكرة: **درع كحلي غامق بطبقات شفافة على خلفية بيضاء** (حماية)

### النصائح (داخل الإعدادات)
- مقسمة بمواضيع: النوم، التركيز، العادات، البدائل الصحية
- كل موضوع ينفتح لنصائحه
- المحتوى من `FocusTips.swift` الموجود

### الإعدادات (بالترتيب)
1. شريك المساءلة
2. النصائح
3. Premium (قريباً)
4. المساعدة + FAQ
5. المجتمع (قريباً)
6. اللغة
7. السياسات
8. عن التطبيق
9. الحساب

### شاشة الحظر (Shield)
- **الشكل:** خلفية بيضاء + درع كحلي غامق (خفيفة)
- نص تحفيزي يتغير كل مرة: آيات + أحاديث + حكم (مخلوطة)
- اسم القائمة ومتى تنتهي (مثل «نوم — ينتهي الساعة 8 الصبح»)
- زر «ابدأ استراحة» لو باقي له استراحات
- ⚙️ تقنياً: زر الاستراحة يحتاج إضافة جديدة `ShieldAction` extension

## 10. ملاحظات تقنية
- 4 شاشات محذوفة والمشروع ما يبني: `OnboardingView`، `GuideView`، `AboutView`، `BlockScreenView`
- `release-checklist.md` فيه الاسم القديم NoNet / «نونت» — يحتاج تحديث للصملة
- معرّفات الحزمة (Bundle IDs) الحالية فيها `nonet` — نقرر نغيرها قبل إنشاء التطبيق في App Store Connect ولا لا (بعد الإنشاء ما تتغير)
- `FeatureFlags.subscriptionsEnabled = false` يبقى — الاشتراك «قريباً»
- `Features.partnerEnabled` يصير مفعّل في نسخة المتجر
- `AccountStore.needsWelcome` ما يوقف التطبيق عند الفتح
- «احظر للأبد»: المواقع عبر فلتر محتوى الويب في ManagedSettings + قائمة دومينات جاهزة، وقفل 17+ عبر حد تقييم متجر التطبيقات
- نص الاشتراك الحالي في الإعدادات يقول إن Premium يفتح الجدولة والاستراحات — يتعدل لأنها مجانية في v1
- `docs/notes.md` فيه سؤال قديم عن الرئيسية — جوابه في قسم «الرئيسية» تحت
